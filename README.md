# NODEUNO: THE ADAPTIVE LEARNING ARCHITECTURE

{App Doc}[https://github.com/kritakHERE/NodeUno/blob/main/appDoc.md]
## 1. PROJECT OVERVIEW
NODEUNO IS A REVOLUTIONARY ADAPTIVE LEARNING PLATFORM DESIGNED FOR THE MODERN INTELLECTUAL. IT COMBINES MULTI-MODEL AI INFERENCE WITH DYNAMIC CURRICULUM GENERATION AND SPATIAL KNOWLEDGE VISUALIZATION. THE SYSTEM IS ENGINEERED TO ELIMINATE THE FRICTION OF LEARNING COMPLEX TOPICS BY AUTOMATICALLY STRUCTURING INFORMATION INTO HIERARCHICAL NODES, SUPPLEMENTED BY DEEP-DIVE RESEARCH AND PRODUCTIVITY-FOCUSED FOCUS SESSIONS.

## 2. CORE FEATURES
- **HYBRID AI BRAIN**: INTEGRATED SUPPORT FOR GOOGLE GEMINI, GROQ (LLAMA/MIXTRAL), CEREBRAS, OPENAI, AND OPENROUTER.
- **HIERARCHICAL KNOWLEDGE TREES**: RECURSIVE CURRICULUM GENERATION THAT ALLOWS FOR INFINITE EXPANSION INTO SUB-TOPICS.
- **3D SPATIAL KNOWLEDGE GRAPH**: FORCE-DIRECTED 3D VISUALIZATION OF THE LEARNING JOURNEY, MAPPING CONNECTIONS BETWEEN DISPARATE NODES.
- **FORCED FOCUS SYSTEM**: INTEGRATED POMODORO TIMER WITH BIOLOGICAL WELL-BEING PROMPTS TO PREVENT COGNITIVE BURNOUT.
- **DUAL-MODE CONTENT SYNTHESIS**: TOGGLE BETWEEN HIGH-LEVEL CORE OVERVIEWS AND EXTENSIVE ACADEMIC DEEP DIVES.
- **SMART CONTEXT LINKING**: HIGHLIGHT ANY TEXT TO INSTANTLY DEFINE IT OR SPAWN A NEW CONNECTED KNOWLEDGE NODE.

## 3. USER JOURNEY
1. **INITIAL CONFIGURATION**: THE USER SELECTS AN AI PROVIDER AND CONFIGURES API KEYS. THEY SET THE BASE DIFFICULTY LEVEL (BEGINNER TO EXPERT OR KINDERGARTEN TO PHD).
2. **GOAL DEFINITION**: THE USER INPUTS A LEARNING GOAL. OPTIONALLY, THEY UPLOAD A PDF OR TEXT FILE TO PROVIDE SOURCE MATERIAL FOR THE CURRICULUM.
3. **ARCHITECTURE BUILD**: THE AI GENERATES A MULTI-PHASE CURRICULUM. THE USER CAN EXPAND ANY SUB-TOPIC AT WILL.
4. **ACTIVE LEARNING**: THE USER EXPLORES INDIVIDUAL TOPICS. THEY CAN TRIGGER "DEEP DIVES," SIMPLIFY CONCEPTS VIA "ESSENTIALS," OR RESEARCH EXTERNAL SOURCES VIA STRATEGIC QUERIES.
5. **KNOWLEDGE MAPPING**: AT ANY TIME, THE USER CAN SWITCH TO THE GRAPH VIEW TO SEE HOW TOPICS INTERRELATE AND IDENTIFY "MISSING LINKS."
6. **FOCUSED RETENTION**: THE USER UTILIZES THE FOCUS TIMER TO MANAGE LEARNING BLOCKS, RECORDING TAGGED NOTES ALONG THE WAY.

## 4. ARCHITECTURAL MODULES
- **CURRICULUM ARCHITECT**: HANDLES THE GENERATION OF THE HIERARCHICAL STRUCTURE (LEVEL 1, LEVEL 1.1, ETC.).
- **KNOWLEDGE SYNTHESIZER**: RESPONSIBLE FOR THE CORE MARKDOWN CONTENT, DEEP DIVES, AND ANALOGY-BASED SIMPLIFICATIONS.
- **RESEARCH ENGINE**: GENERATES OPTIMIZED SEARCH STRATEGIES FOR GOOGLE AND YOUTUBE.
- **VISUALIZATION ENGINE**: USERS REACT-FORCE-GRAPH-3D TO RENDER THE RELATIONAL TOPOLOGY OF THE TOPIC SPACE.
- **SESSION CONTROLLER**: MANAGES THE FOCUS/BREAK CYCLES AND PERSISTS STATE TO LOCAL STORAGE.

## 5. API AND INTEGRATIONS
- **GEMINI API**: UTILIZED FOR MULTIMODAL GROUNDING, GOOGLE SEARCH INTEGRATION, AND HIGH-QUALITY REASONING.
- **LLM PROVIDERS (GROQ/CEREBRAS/OPENAI)**: USED FOR RAPID GENERATION OF JSON-FORMATTED KNOWLEDGE STRUCTURES.
- **DICTIONARY API**: PROVIDES INSTANT LINGUISTIC DEFINITIONS WITHOUT CONSUMING LLM TOKENS.
- **PDFJS INTEGRATION**: ALLOWS FOR LOCAL PARSING OF PDF DOCUMENTS TO INJECT CONTEXT INTO PROMPTS.

## 6. TECHNICAL SPECIFICATIONS
- **FRAMEWORK**: REACT WITH TYPESCRIPT.
- **STYLING**: TAILWIND CSS WITH GLASSMORPHISM UI DESIGN.
- **PERSISTENCE**: FULL STATE SYNC TO BROWSER LOCALSTORAGE.
- **VISUALS**: 3D WEBGL VIA THREE.JS (REACT-FORCE-GRAPH-3D).
- **MARKDOWN**: GFM-COMPLIANT REACT-MARKDOWN RENDERING.

## 6.1 SECRETS / ENV SETUP (SYSTEM KEYS VS USER KEYS)
- **SYSTEM KEYS (RECOMMENDED)**: SET `GROQ_API_KEY` AND `OPENROUTER_API_KEY` ON THE BACKEND (EXPRESS IN `server/index.js`). THE FRONTEND WILL CALL `/api/*` AND YOUR KEYS STAY SERVER-SIDE.
- **USER KEYS (OPTIONAL)**: USERS CAN ENTER THEIR OWN PROVIDER KEYS IN **SETUP → CONFIGURE KEYS**. THESE ARE STORED LOCALLY IN THE BROWSER (LOCALSTORAGE).
- **DO NOT COMMIT SECRETS**: COPY `.env.example` → `.env` AND PUT REAL KEYS THERE. `.env` / `.env.local` MUST NEVER BE COMMITTED.
- **BACKEND URL**: IF YOUR BACKEND IS NOT ON THE SAME ORIGIN, SET `VITE_BACKEND_URL` (NON-SECRET) SO THE FRONTEND CAN REACH IT.

### GITHUB SECRETS
- REPO → SETTINGS → SECRETS AND VARIABLES → ACTIONS → ADD `GROQ_API_KEY`, `OPENROUTER_API_KEY`.
- NOTE: GITHUB SECRETS ONLY APPLY INSIDE GITHUB ACTIONS RUNS. YOU STILL NEED TO INJECT THEM INTO YOUR DEPLOYMENT (HOST ENV VARS) OR INTO YOUR WORKFLOW THAT STARTS/DEPLOYS THE BACKEND.

## 7. MAINTENANCE AND EXTENSIBILITY
THE SYSTEM IS DESIGNED TO BE MODULAR. NEW AI PROVIDERS CAN BE ADDED TO THE `services/gemini.ts` WRAPPER. NEW CONTENT MODALITIES CAN BE INJECTED BY UPDATING THE `SYSTEM_PROMPTS` CONSTANT IN `constants.ts`.
